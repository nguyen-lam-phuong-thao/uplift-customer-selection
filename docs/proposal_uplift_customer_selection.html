Phase 2 expansion

From method lab to retail case study.

Criteo is used to test the uplift workflow first. RetailHero then reuses the same pipeline, configs, and metrics — but trains a separate model on retail customers.

01
Prototype on Criteo
Validate the full flow: treatment/control, outcome, uplift score, Qini, AUUC, Top-K, and budget policy.
02
Reuse the framework
Keep the same project structure, model interfaces, config files, and evaluation logic; replace only dataset-specific features.
03
Apply on RetailHero
Aggregate purchases, products, and profiles; retrain the uplift model; then explain high-uplift customer segments.
